# 야구알리미

KBO 리그 **순위 · 가을야구 · 구단별 성적 · 선수 정보 · 야구 뉴스**를 한 화면에서 보는 앱입니다.
휴대폰 홈 화면에 설치하면 주소창 없이 앱처럼 열립니다(PWA). 해마다 새 시즌으로 저절로 넘어갑니다.

> 오른쪽 위 **내 팀** 창 아래 "제목 뒤에 이름 붙이기"에 이름을 넣으면, **그 기기에서만** 제목이 "야구알리미 for ○○" 로 바뀝니다.
> 이름은 그 기기의 브라우저에만 저장되고 이 저장소·공개 사이트에는 들어가지 않습니다.

## 여는 방법

- **사이트**: https://zenki798.github.io/baseball-alimi/
- **휴대폰 앱으로**: 위 주소를 휴대폰 브라우저로 열고 홈 화면에 추가합니다.
  안드로이드 크롬은 화면 아래 "앱으로 설치" 단추, 아이폰은 사파리 공유 단추 → "홈 화면에 추가".
- **이 PC 에서**: `index.html` 을 더블클릭합니다. (마지막으로 모은 자료가 뜹니다. 선수 사진만 인터넷이 필요합니다)

## 화면

| 화면 | 내용 |
|---|---|
| 순위 | 정규시즌 순위표(승률·게임차·연속·최근 5경기·가을야구 진출 확정/탈락 배지), 날짜별 경기 결과, 내 팀 요약 |
| 가을야구 | 정규시즌 중: 1~5위 자리와 시작 라운드, 진출 확정·경쟁·탈락, 최종 순위로 가능한 범위 / 정규시즌 뒤: 와일드카드 → 준플레이오프 → 플레이오프 → 한국시리즈 대진·시리즈 승수·경기 결과, 우승팀. 내 팀이 어디까지 갔는지 한 줄로 |
| 팀 | 구단 엠블럼·연고지·구장, 성적(1위·5위와의 거리, 남은 경기, 홈/원정), 최근 경기, 선수단·코칭스태프, 팀 뉴스 |
| 선수 | 이름·초성(예: `ㄱㄷㅇ`)·등번호로 찾기, 프로필(생년월일·투타·키/몸무게·경력·수상), 얼굴 사진(누르면 크게), **연도별 기록**(지난 시즌까지) + **KBO 공식 기록** 버튼(올 시즌), 관련 뉴스 |
| 뉴스 | KBO·해외야구·대표·아마 / 구단별 거르기, 검색. 누르면 언론사 원문으로 |

오른쪽 위 **내 팀**을 고르면 순위표에서 강조되고 첫 화면에 요약이 나옵니다(이 기기에만 저장).

## 자료가 바뀌는 방법

`scripts/collect.js` 가 자료를 모아 `data/live.js`·`data/players.js` 를 만듭니다.

- 순위·경기 결과·뉴스: 돌 때마다 / 가을야구 대진: 정규시즌 막바지부터 돌 때마다 / 명단·선수 프로필·사진: 20시간마다
- 시즌: 새해 새 시즌 문서에 첫 경기 결과가 올라오면 그 시즌으로 넘어가고, 그 전(겨울)에는 지난 시즌 결과를 그대로 보여 줍니다
- **자동으로**: `.github/workflows/collect.yml` 이 30분마다 수집 → 전체 테스트 → 통과하면 배포합니다
  (GitHub 예약 실행은 늦어지거나 건너뛸 때가 있습니다. 늦어지면 바닥글이 알려 줍니다).
- **이 PC 에서 손으로**: `npm run collect` (명단까지 지금 새로: `FORCE_PLAYERS=1 npm run collect`)

자료는 위키백과 편집자들이 고치는 속도를 따라갑니다. 순위는 보통 그날 밤, 명단은 며칠 안에 바뀝니다.

## 자료 출처와 이용 조건

| 자료 | 출처 | 조건 |
|---|---|---|
| 순위표 | 영문 위키백과 「(시즌) KBO League season」 | CC BY-SA 4.0 |
| 가을야구 대진·경기 기록 | 한국어 위키백과 「(시즌)년 KBO 포스트시즌」·「(시즌)년 한국시리즈」 + 연합뉴스 전적 기사 제목 | CC BY-SA 4.0 |
| 명단·선수 프로필 | 한국어 위키백과 (구단별 명단 틀, 선수 문서 정보 상자) | CC BY-SA 4.0 |
| 선수 연도별 기록 | 한국어 위키백과 선수 문서의 「통산 기록」 표 (지난 시즌까지) | CC BY-SA 4.0 — 편집자가 정리한 값이라 공식 기록과 다를 수 있음 |
| 올 시즌 기록 | KBO 공식 기록 페이지 **링크** (선수 번호는 위키백과에 적힌 것) | 이 앱은 KBO 자료를 모으지 않고 링크만 겁니다 |
| 선수 사진 | 위키미디어 공용 (자유 이용 사진만) | 사진마다 작성자·라이선스 표기 |
| 구단 엠블럼 | 위키미디어 공용 (퍼블릭 도메인 — 단순 글자 로고) | 상표권은 각 구단 — `icons/teams/README.md` |
| 뉴스·경기 결과 | 언론사 RSS (연합뉴스·뉴시스·조선일보·경향신문·SBS·일간스포츠·동아일보·한겨레) | 제목·링크·짧은 발췌만, 저작권은 각 언론사 |

KBO 공식 사이트와 네이버 스포츠는 자동 수집을 금지(robots.txt)하므로 자료를 가져오지 않습니다.
그래서 **올 시즌 개인 기록은 앱 안에 없고(KBO 공식 기록 버튼으로 봅니다), 경기 일정·선발 투수도 아직 없습니다.**

이 앱은 KBO·각 구단과 관계없는 개인 프로젝트입니다.

## 개발

```bash
npm start              # http://localhost:4211
npx playwright test    # 전체 테스트 (AGENTS.md 규칙 1 — 고친 뒤에는 반드시)
npm run check:sensitive  # 민감정보 검사 (커밋할 때는 자동)
```

작업 규칙은 [AGENTS.md](AGENTS.md) 에 있습니다.

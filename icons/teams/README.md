# 구단 엠블럼 출처

모두 위키미디어 공용(Wikimedia Commons)에서 2026-10-02 받은 파일이다. 공용은 이 파일들을
**퍼블릭 도메인(PD-textlogo — 단순한 글자·도형 로고라 저작권 보호 대상이 아님)** 으로 분류한다.
그래서 저작권 허락 없이 쓸 수 있다.

**상표권은 각 구단에 있다.** 이 앱은 경기·순위에서 *어느 팀인지 알아보게 하는 표시*로만 쓴다
(비상업 개인 앱). 상품·광고에 쓰거나, 구단이 만든·인정한 앱처럼 보이게 쓰지 않는다.
화면 바닥글에 "KBO·각 구단과 관계없는 개인 프로젝트" 안내를 늘 둔다.

- 한화는 공용에 모자 엠블럼(insignia)이 없어 글자 로고를 쓴다. 글자가 길어 작게 줄이면 읽을 수 없으므로
  작은 자리(표·목록)에서는 구단 색 배지를, 큰 자리(팀 화면 머리)에서만 이 로고를 쓴다 (`teams.js` 의 `logoWide`).
- SVG 는 받을 때 스크립트·이벤트 속성·바깥 주소 참조가 없는지 확인했다. 화면에서는 `<img>` 로만 넣는다(SVG 안 스크립트가 돌 수 없다).
- 파일을 바꾸거나 더할 때도 **공용에서 퍼블릭 도메인으로 분류된 것만** 쓰고, 이 표에 원본 주소를 적는다.
  비자유(공정 이용) 로고 — 예: 영문 위키백과에만 올라 있는 구단 로고 — 는 쓰지 않는다.
